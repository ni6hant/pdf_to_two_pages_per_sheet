# PDF 2 Pages Per Sheet
Put the [executable from releases page](https://github.com/ni6hant/pdf_to_two_pages_per_sheet/releases) it [in your windows `path`](https://www.youtube.com/watch?v=SD4g1OaUFXA). And run it directly from the location of PDF by putting the executable name in the address bar on Windows. This will save the time of finding the location of the PDFs.

# Building
Run `build.bat` . The executable will be located in: `dist/pdf2up.exe`.
